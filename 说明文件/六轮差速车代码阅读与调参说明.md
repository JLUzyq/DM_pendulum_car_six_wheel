# 六轮差速车代码阅读与调参说明

## 1. 先看懂数据流

程序每次控制循环按下面顺序工作：

1. 遥控接收代码读取前进和转向摇杆。
2. `freertos.c` 把前进摇杆换算成 `v_set`，把转向摇杆积分成 `yaw_set`。
3. `chassis_task.c` 从 IMU 读取实际航向角 `yaw` 和航向角速度 `d_yaw`。
4. 航向 PD 控制器计算差速修正量 `turn_out`。
5. `kinematics.c` 把 `v_set` 和 `turn_out` 换算成左右两侧速度，再展开为六个电机速度。
6. `hm_motor.c` 把浮点速度编码成 G36 的 8 字节 MIT 报文。
7. `can_bsp.c` 通过 CAN1/CAN2 发送命令，并按独立反馈 ID 接收六台电机状态。

最重要的配置集中在 `User/APP/vehicle_config.h`。修改电机 ID、安装方向、
车轮尺寸、速度上限或控制参数时，应先检查这个文件。

## 2. 六轮差速运动学

车体前进速度为 `v`，转向修正为 `turn_out`：

```text
v_left  = v + turn_out
v_right = v - turn_out
```

电机角速度由 `omega_motor = v_side / wheel_radius` 得到。右侧电机与左侧镜像
安装，所以每台电机还要乘配置表中的 `dir`。若某个车轮方向错误，只修改该电机
的 `dir`（`+1.0f` 或 `-1.0f`），不要在运动学公式中临时改正负号。

## 3. 航向 PD 控制器

代码使用：

```text
yaw_error = yaw - yaw_set
turn_out  = YAW_KP * yaw_error - YAW_KD * d_yaw
```

- `YAW_KP`：车辆偏离目标方向后，产生多大的回正速度差。
- `YAW_KD`：车辆正在旋转时施加阻尼，减小过冲和左右摆动。
- 当前初值：`YAW_KP=0.4`，`YAW_KD=0.02`。
- 这两个参数控制整车航向，和电机 MIT 报文里的 `Kd` 不是同一个参数。

推荐调参：

1. 架空车辆，确认六个车轮的正方向和反馈方向。
2. 限制低速，把 `YAW_KD` 暂设为 0，从较小 `YAW_KP` 开始。
3. 逐渐增大 `YAW_KP`，直到回正速度合适或刚出现轻微摆动。
4. 逐渐增大 `YAW_KD`，消除过冲和摆动。
5. 依次测试原地转向、低速直行、带载转向和遥控掉线保护。

## 4. G36 MIT 速度参数

纯速度模式报文使用：

```text
P_des = 0
V_des = 目标电机角速度
Kp    = 0
Kd    = G36_VELOCITY_KD
T_ff  = 0
```

`G36_VELOCITY_KD` 是电机内部的速度调节增益：

- 太小：电机发软、带载掉速；
- 太大：冲击、电流和噪声增大，可能抖动；
- 当前值 `2.1` 是厂家推荐起点，不是整车航向 PD 的 `YAW_KD`。

## 5. CAN ID 对照

| 车轮 | 命令 ID | 反馈 ID | 总线 |
|---|---:|---:|---|
| 左前 | `0x01` | `0x11` | CAN1 |
| 左中 | `0x03` | `0x13` | CAN1 |
| 左后 | `0x05` | `0x15` | CAN1 |
| 右前 | `0x02` | `0x12` | CAN2 |
| 右中 | `0x04` | `0x14` | CAN2 |
| 右后 | `0x06` | `0x16` | CAN2 |

反馈帧通过 `RxHeader.Identifier` 匹配电机，不能再按默认的 MASTER_ID=0
或只依赖 `data[0]` 分发。

## 6. 学生调试时的安全顺序

1. 先架空车轮，确认使能、停机和遥控掉线保护。
2. 单独检查每个电机 ID、总线和旋转方向。
3. 低速运行，确认反馈速度的正负与指令一致。
4. 再调电机速度 `Kd`，最后调整车航向 `YAW_KP/YAW_KD`。
5. 每次只改一个参数并记录现象，不要同时修改多个增益。
