# 偏航角速度 PI 调参页

## 启动

在仓库根目录打开 PowerShell 并运行：

```powershell
python -m http.server 8000
```

使用桌面版 Chrome 打开：

```text
http://localhost:8000/tuning/yaw_rate_tuner.html
```

Web Serial 需要 `localhost` 或 HTTPS 安全上下文。当前页面通过 USB 转串口直连底盘 USART1（115200 8N1）；同一个 COM 口不能同时被其他串口软件占用。

## 调参步骤

1. 确认 USB 转串口已连接到底盘 USART1，并关闭其他占用该 COM 口的程序。
2. 点击“连接串口”，在 Chrome 设备选择框中选择对应 COM 口。
3. 点击遥测开关。页面查询并显示下位机当前生效的 Kp/Ki，然后开始显示理论角速度和 IMU 实际角速度曲线。
4. 输入 Kp（`0..10`）和 Ki（`0..1`），点击“应用参数”。收到下位机确认后，页面显示生效值。
5. 结束调参时关闭遥测，再断开串口。串口意外断开或页面关闭时，下位机在 1.5 秒心跳超时后自动停止上传。

调参页不发送车辆运动指令；调参行驶请使用 SBUS 遥控器，并按现有 CH8 控制源逻辑选择遥控模式。PI 参数仅存于 RAM，底盘重启后恢复 `vehicle_config.h` 中的默认值（Kp=0.30、Ki=0）。页面曲线显示最近 10 秒；CSV 可导出最多最近 1 小时的采样记录。
